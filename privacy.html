Privacy

Privacy at FindYourHabits

FindYourHabits is designed to work without an account. Your habit names, check-ins, notes and settings are stored locally in your browser rather than in a FindYourHabits user database.

Your habit data

Your tracker data is saved using your browser's local storage on the device and browser you use. FindYourHabits does not require you to create an account or submit your habit data to a FindYourHabits server.

Backups and exports

If you choose to export a JSON backup or CSV file, that file is created for you to save. You are responsible for keeping exported files secure. Importing a JSON backup reads the file in your browser to restore your tracker.

Website analytics

FindYourHabits uses Cloudflare Web Analytics to understand basic site usage, such as visits and page views. This helps improve the website. The analytics service is separate from the habit data stored in your browser.

Third-party services

The site is delivered using GitHub Pages and uses Cloudflare services for the domain and analytics. Those providers may process technical information needed to deliver and protect the website in accordance with their own privacy practices.

Clearing your data

You can clear tracker information using the reset controls in FindYourHabits. Clearing your browser's site data for findyourhabits.com can also remove locally stored tracker information, so export a backup first if you want to keep it.

Changes to this page

This privacy page may be updated as FindYourHabits changes. The current version was updated in October 2026.
